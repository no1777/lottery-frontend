📋 概述

六合彩开奖系统外部 API，开发者可通过 API Key 获取开奖数据。

Base URL: https://api.vnlotto.vip/api

认证方式: 所有接口需在请求头中携带 X-API-Key

X-API-Key: mk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

💡 在 用户端 注册登录后可申请 API Key，需管理员激活。

📊 获取当前开奖 需要 API Key

GET /v1/draw/current

获取最新一期的开奖号码。

📥 响应示例

{ "success": true, "data": { "period": 9, "numbers": [1, 38, 28, 5, 10, 30, 17], "draw_time": "2026-07-30T13:30:00.034Z" } }

💡 示例

curl -X GET https://api.vnlotto.vip/api/v1/draw/current \ -H "x-api-key: mk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
字段类型说明
periodinteger期数
numbersarray7个开奖号码
draw_timestring开奖时间 (ISO 8601)

📋 获取开奖历史 需要 API Key

GET /v1/draw/history

获取历史开奖记录，支持分页。

参数类型说明
limitinteger每页数量（默认 20）
offsetinteger偏移量（默认 0）

📥 响应示例

{ "success": true, "data": [ { "period": 9, "numbers": [...], "draw_time": "..." } ], "pagination": { "limit": 5, "offset": 0, "total": 9 } }

💡 示例

curl -X GET "https://api.vnlotto.vip/api/v1/draw/history?limit=5&offset=0" \ -H "x-api-key: mk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

📊 获取号码频率 需要 API Key

GET /v1/stats/frequency

统计每个号码在所有历史开奖中出现的次数，按频率降序排列。

📥 响应示例

{ "success": true, "data": [ { "number": 11, "count": 4 }, { "number": 10, "count": 3 } ] }

💡 示例

curl -X GET https://api.vnlotto.vip/api/v1/stats/frequency \ -H "x-api-key: mk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

⏰ 获取开奖时间配置 需要 API Key

GET /v1/config/draw-time

获取每日固定开奖时间，用于同步倒计时。

📥 响应示例

{ "success": true, "data": { "draw_time": "20:30" } }

💡 示例

curl -X GET https://api.vnlotto.vip/api/v1/config/draw-time \ -H "x-api-key: mk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

❌ 错误码

状态码含义解决方法
200成功-
400请求参数错误检查参数格式
401缺少 API Key添加 X-API-Key 请求头
403API Key 无效或未激活联系管理员激活
404接口不存在检查 URL 路径
429请求频率超限降低调用频率（每分钟60次）
500服务器内部错误稍后重试或联系管理员
